## 0. 背景与边界

| 项 | 口径 |
|----|------|
| 现网（PR#65 后） | 服务端 VLM 检框切图 → 确认页 → 仍偏「投稿/匹配」旧组合；张数上限多为 9/12；手动 4/9 易藏在高级项 |
| 本切目标 | **入册策略固化** + **切图入口显式二选一** + **AI 上限 16** |
| 不变 | 禁止未确认灌库；禁止模型自动写特典文案并 published；密钥仅服务端；登录/审核状态机仍属 UGC-1 |
| 端 | 微信小程序优先；H5 宫格仍 Out（与 VLM freeze 一致） |

---

## 1. 一句话

用户在宫格入册入口**显式选择**「AI 切图」或「手动四宫/九宫」；确认每张切图后，对每卡做 **published 图鉴匹配**：命中则**直接挂拥有入册**，未命中则**走 UGC-1 审批投稿**；版本字段可选不填；AI 路径检测与提交上限均为 **16**。

---

## 2. In Scope

### 2.1 入册策略（相对现网差异）

| # | 能力 | 口径 |
|---|------|------|
| 1 | 匹配优先 | 用户确认卡位/切图之后，**每张卡**对 catalog 中 **published** 模板做图鉴匹配（近 dup / 现有匹配服务，阈值沿用现网） |
| 2 | 命中路径 | 匹配成功 → **直接挂拥有**（UserCard / 拥有关系），**不**再强制进 `pending_review` 投稿 |
| 3 | 未命中路径 | 匹配失败 → **走审批投稿**（UGC-1：`pending_review` → 审通过后才可能 published / 挂拥有，规则同 UGC-1） |
| 4 | 版本字段 | **不必填**（可选）；UI 可弱提示，缺省不挡提交 |
| 5 | 确认门槛 | **仍须**用户在确认页确认后才触发匹配/投稿；**禁止**检测完成即灌库 |
| 6 | 文案 | 模型或 OCR「建议」可预填，**须用户确认**；**禁止**自动 published 文案 |

### 2.2 切图方式自选（入口）

| # | 能力 | 口径 |
|---|------|------|
| 1 | 入口显式 | 宫格入册主流程**第一屏/明显入口**提供二选一：「**AI 切图**」｜「**手动四宫/九宫**」 |
| 2 | 禁止仅折叠 | 不得只藏在「高级 / 更多」折叠里；可保留高级说明，但主路径必须可见 |
| 3 | AI 路径 | 走 UGC-2b-VLM：整页上传 → 服务端检测切图 → 确认页（上限见 2.3） |
| 4 | 手动路径 | 走规则宫格：用户选手选 4 或 9 → jsfeat/投影切（或现网手动切实现）→ 同一确认页语义 |
| 5 | 确认页复用 | 两种入口汇入同一确认能力（调框/删卡/旋转/补单卡等，以现网为准） |

### 2.3 张数上限

| # | 能力 | 口径 |
|---|------|------|
| 1 | AI 检测上限 | 服务端 VLM 返回卡位 **最多 16**；超出截断或提示用户删减（产品文案需一致） |
| 2 | AI 提交上限 | 确认后一次提交 **最多 16** 张；原 12/9 **不再作为本切 AI 默认上限** |
| 3 | 手动路径 | 四宫=4、九宫=9（规则宫格本身上限）；不强制扩到 16 |
| 4 | 作废默认 | 文档/配置中「AI 默认 9 或 12」改为 **16** |

### 2.4 工程与安全（沿用）

| # | 能力 | 口径 |
|---|------|------|
| 1 | 密钥 | 视觉模型 API Key **仅服务端** |
| 2 | 存储 | 切图/临时件前缀与 UGC-2b-VLM 一致；确认前提交不 published |
| 3 | 审计 | 可沿用/扩展现有投稿与拥有写入日志；本切不强制新 Admin 统计页（见 Admin VLM 统计另包） |

## 3. Out of Scope

| Out | 说明 |
|-----|------|
| 未确认灌库 | 检测完直接写拥有或 published |
| 自动 published 文案 | 模型写特典名/成员并直接上架 |
| 端侧跑大模型 | 小程序本地 VLM |
| H5 宫格入册 | 与 VLM freeze 一致暂不做 |
| 改 UGC-1 状态机核心 | 未命中仍走先审后发；不引入「免审自动上架」 |
| 短信/手机号 | 见包 B，不在本切 |
| 交易/交换 | 不新开 |
| 强制填写版本 | 版本为可选 |

## 4. 与现网差异摘要

| 维度 | 现网（VLM PR#65 前后） | 本切 |
|------|------------------------|------|
| 确认后默认 | 偏批量申请 / 可选匹配（口径易混） | **先匹配 published：命中挂拥有；未命中投稿** |
| 切图入口 | AI 主路径，手动易藏深 | **入口显式 AI ‖ 手动 4/9** |
| AI 张数 | 常见 9/12 | **检测+提交 ≤ 16** |
| 版本 | 视现网表单 | **可选，可不填** |

---

## 5. 验收条目（建议）

1. 入口可见「AI 切图」与「手动四宫/九宫」两选项，非仅高级折叠。  
2. AI 路径：整页不规则多卡可检出并切图；确认页可删至 ≤16；一次确认提交不超过 16。  
3. 确认后：对 published 命中的卡，用户柜中出现拥有且**无**对应 pending 投稿（或明确标记为匹配入册，无审流）。  
4. 确认后：未命中卡进入 UGC-1 审批流，状态与机审/白名单规则与现网一致。  
5. 全程无「跳过确认直接灌库」；服务端无客户端明文模型密钥。  
6. 版本字段空值可提交（命中与未命中路径均成立）。  
7. 手动 4/9 仍可用，并汇入同一确认语义。

## 7. 风险与影响声明

| 风险 | 缓解 |
|------|------|
| 误匹配挂错拥有 | 确认页可删卡；匹配置信门槛；用户可后续从柜中移除（若现网支持） |
| 16 张费用/延迟 | 沿用 VLM 计费上限与超时降级；可提示「张数多耗时」 |
| 与旧「全量投稿」习惯冲突 | 文案写清「图鉴已有直接入柜，没有则送审」 |
| 影响声明 | **不改** UGC-1 状态机枚举本身；**不改** Admin ops 登录；密钥策略不变 |
