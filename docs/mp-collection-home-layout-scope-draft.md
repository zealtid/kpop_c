## 0. 背景与边界

| 项 | 口径 |
|----|------|
| 现网 | 底栏首 Tab 文案「卡册」；页内「我的卡册」+「拍照加入卡册」；按已关注组合列 logo、owned/published、进度条；下钻 `cardbook-group`；数据 `GET /collection/overview` + `/me/follows` |
| 参考 | 第三方 Collections / Bias Zone 风格附图（调研稿 §2） |
| 本切原则 | **只 enrich 布局与命名**；**没有的功能先不加**；能力仅复用现网已有 |
| 路径 | 路由可暂留 `pages/cardbook`（减风险）；只改文案、布局、入口 |

---

## 1. 一句话

把底栏与页内标题统一为「**收藏**」；页顶做**双入口**（左→收藏/组合列表，右→拍照入册），下半**保留并优化**关注组合进度卡片，并**显著展示用户喜欢的小卡图作组合封面**（非团图标）；视觉可向参考靠拢但仍跟星卡色板——**不加**通知、私信、Bias、心愿页、6 Tab、游戏化里程碑、团图标当封面等。

---

## 2. In Scope（仅已有能力）

### 2.1 命名

| # | 能力 | 口径 |
|---|------|------|
| 1 | 底栏 tabBar | 文案改为「**收藏**」（原「卡册」） |
| 2 | 页内标题 | 改为「**收藏**」（原「我的卡册」/「卡册」） |
| 3 | 相关文案 | 页内按钮、空态、analytics 事件名/属性中的展示文案若仍写「卡册/我的卡册」，本切一并改到「收藏」（技术 event key 可保留旧值以免断数，见 OQ-L1） |
| 4 | 路径 | **可不改** `pages/cardbook*` |

### 2.2 顶区双入口

| # | 能力 | 口径 |
|---|------|------|
| 1 | 视觉 | 双入口并排，视觉可参考用户附图大圆角/主色强调；**色板跟星卡现网**，不强制竞品纯黑+粉 |
| 2 | 左入口 | 文案语义「收藏」/组合列表；行为：滚到本页组合列表锚点，或等同展开/聚焦现有列表（**不**新开独立信息架构页） |
| 3 | 右入口 | **拍照入册** → 现网宫格入册（`catalog-grid` / 现「拍照加入卡册」目标页）；**不是**心愿单 |
| 4 | 计数（可选） | 左钮可带已关注组合数或 owned 概览数（现有 overview/follows 字段）；无则可不显示数字，不挡本切 |

### 2.3 组合进度列表（保留并优化）

| # | 能力 | 口径 |
|---|------|------|
| 1 | 数据 | 仍按**已关注组合**；logo、团名、owned/published、进度条/% |
| 2 | 交互 | 点进现网 `cardbook-group`（或等价下钻） |
| 3 | 布局 | 重排/丰富卡片层级与留白（更大圆角、更清晰进度），对标参考图下半「进度列表」语义，**不是**成员 Bias |
| 4 | 历史私人卡 | 若现网本页仍有私人卡网格：本切可保留或轻量收拢到次要区；**不**借机扩 Album-N |



### 2.3a 组合卡「喜欢的小卡」封面（2026-09-16 修订）

| # | 能力 | 口径 |
|---|------|------|
| 1 | 展示 | 「收藏」列表每个关注组合卡的主视觉 = **用户自己的小卡图**（图鉴模板主图 / 用户拥有卡面），**不是**团 `icon_url`/`logo_url` |
| 2 | 选图来源 | 仅该组合下用户**已拥有**（`user_cards`）的 published 模板图；无拥有则占位（色块/首字或「去收集」），**不**回退成团图标冒充封面 |
| 3 | 选定方式 | **已拍：用户可指定**该团封面小卡（须为该团已拥有）；未指定前可用自动占位/最近获得作临时展示（OQ-C2） |
| 4 | 团图标 | 可保留为次要小标（可选）；**不得**作为封面主图 |
| 5 | 存储 | 新增轻量关联（建议 `user_group_covers(user_id, group_id, template_id)` 或等价）；换绑/失去拥有时校验，失效则清空并回退 |
| 6 | 设置入口 | 组合下钻页或列表长按/「设为封面」；仅能选该团已拥有卡 |

### 2.4 登录 / 空态

| # | 能力 | 口径 |
|---|------|------|
| 1 | 未登录 | 保留现网引导登录语义 |
| 2 | 已登录无关注 | 保留「去关注组合」等空态语义；文案随「收藏」命名微调即可 |

### 2.5 视觉

| # | 能力 | 口径 |
|---|------|------|
| 1 | 靠拢参考 | 大圆角卡片、更强主色强调双入口与进度卡 |
| 2 | 主题 | **跟星卡现网色板**（浅色为主可接受）；不强制深色仿竞品 |

## 3. Out of Scope（写死）

| Out | 说明 |
|-----|------|
| 通知铃铛 | 无通知产品 |
| 私信 | 无 IM |
| 6 Tab | 仍 3 Tab（收藏 / 图鉴 / 我的）；不改成 Home/Social/Market… |
| PRO / 会员墙 | 不加 |
| Bias Zone | 本命成员切换、成员大图仪表盘、备注、同好人数等 **整包不做** |
| 心愿独立页 | 不做心愿落地页 |
| 心愿三分类 | 小卡/专辑/周边分桶与统计不做 |
| 24h 图鉴增量 | 无 +N(24h) API 则不加 |
| 里程碑游戏化 | 不造 10/50 等体系；**可用**现有 owned/published 进度条 |
| Album-N | 专辑维度产品不做 |
| 交易 / 社交 Tab | 不加 |
| 新后端能力 | 本切以现有 overview/follows/宫格入口为限；不为布局 enrichment 新开统计服务 |
| 团图标当列表封面 | **禁止**；封面必须是用户小卡图 |
| 未拥有时用团图标充门面 | **禁止**；用空态占位 |

## 5. 验收条目（建议）

1. 底栏首 Tab 与本页导航标题均显示「收藏」，无残留「我的卡册」主标题。  
2. 顶区可见双入口：左可到达/聚焦组合列表；右进入现网拍照/宫格入册。  
3. 关注组合卡片主视觉为**用户指定的该团封面小卡**（须已拥有；非团图标）；未指定可用临时自动图；无拥有则占位；另有 owned/published、进度，可进 group 下钻；提供设为封面入口。  
4. 未登录、无关注空态仍可用且文案不矛盾。  
5. 无通知铃、无私信入口、无 Bias/心愿三分类/6 Tab/PRO。  
6. 视觉不强制纯黑+竞品粉；主色与星卡现网一致或同源扩展。

## 7. 风险与影响声明

| 风险 | 缓解 |
|------|------|
| 用户习惯「卡册」找不到 | 位置仍是原首 Tab；仅文案变更 |
| 视觉改动引起回归 | 只动 cardbook 首页布局；下钻 group 页本切可不改或仅随标题 |
| 范围漂向 Bias/心愿 | Out 表写死；评审挡需求加塞 |
| 影响声明 | **不改** UGC-1/2b/VLM、匹配入册、手机号/硬删等后端包；**不增** Tab 数量；**不改** 登录模型 |
