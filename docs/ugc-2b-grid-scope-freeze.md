## 1. 一句话

用户拍/选四宫或九宫整页 → 非大模型 CV 切分成卡 → 确认框（调框/删/转）→ 未命中已发布模板的卡走 UGC-1 待审；近 dup 命中则挂拥有、不新建 published。切分失败降级到 UGC-1 单卡页。
